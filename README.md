# 役割と概要
あなたはPhaser.js (v3) と JavaScript (ES6+) に精通した2D Webゲームデベロッパーです。
『Vampire Survivors』のゲームシステムを完全踏襲した、スマホ・PCブラウザ対応の2Dゲーム『Microbe Survivors（微生物サバイバーズ）』を完全日本語で開発します。

以下のゲームシステム仕様・データ構造を満たすプロトタイプコード（`index.html` と `game.js`）を生成してください。

---

# 1. ゲームシステム仕様（ヴァンサバ完全踏襲）

1. **レベルアップ選択**
   - 敵を倒して出る「処理エネルギー（オーブ）」で経験値獲得。
   - レベルアップ時にゲームが一時停止し、日本語の選択用モーダルを表示。
   - 「未習得スキルの新規獲得」または「習得済みスキルのレベルアップ（威力・範囲・冷却時間などの強化）」を選択可能。
   - **所持枠制限:** キャラクターが習得できるスキルは**最大6個まで**。6個埋まっている場合は既存スキルのレベルアップのみ出現。

2. **スキルの進化（Evolution）システム**
   - 特定のスキルが「最大レベル（Lv.5等）」に達し、かつ特定のサブスキル（または特定条件）を満たした状態で宝箱/特定イベントを獲得すると、上位の「進化スキル」に変化する仕組みを構築。

3. **メタプログレッション（永続強化・解放要素）**
   - プレイヤーの永続ステータス（`localStorage` に保存）を用意。
   - 特定ステージクリア等の報酬として「レベルアップ時の選択肢枠の増加（初期3枠 ➔ 4枠へ拡張）」や「リロール回数」を永続解放できるデータ構造。

4. **完全日本語化**
   - UI、スキル名、説明文、敵の名前、ログ、ポップアップテキスト等、すべて日本語で記述。

---

# 2. データ構造仕様（拡張性を考慮した設計）

後から数値を簡単に調整・追加できるよう、以下のデータをコード冒頭の `GAME_CONFIG` オブジェクトに日本語表記で集約してください。

### A. プレイアブルキャラクター（最低5体）
1. **ツリガネムシ** *(バランス・吸入型)*
2. **アスピディスカ** *(高速・近接型)*
3. **アルセラ** *(高耐久・シールド型)*
4. **クマムシ** *(超高耐久・低速型)*
5. **ミドリムシ** *(自動回復・光合成型)*

### B. スキルデータ（最低15種類）
- 攻撃系・サポート系を含めて最低15種類（例: バネ状触手ビーム、DOブロワー、PAC凝集剤、次亜塩素酸スプレー、pH調整剤、返送汚泥ポンプ、紫外線照射器、ろ過フィルターなど）。
- **進化組み合わせ表（Evolutions）** のデータ定義（例: `DOブロワー Lv.MAX + 返送汚泥ポンプ -> 超高圧エアジェット` など）。

### C. 敵キャラクター（最低20種類）
- BOD（有機物）、SS（浮遊物質）、アンモニア、バルキング糸状菌、センチュウ、ダニ類、スカム等、最低20種類の敵データ（HP、移動速度、攻撃力、経験値）を定義。
- **ウェーブ/ラウンド構成データ（WaveConfig）:** 後から「○分〜○分はこの敵が何体出現する」をラウンドごとに指定できる配列形式のテーブル構造にすること。
